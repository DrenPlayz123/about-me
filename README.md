# Global Anonymous Chatroom

This repository now serves a **global anonymous chatroom website** (not an About Me page).

## What users get

- Live global chat shared by everyone currently on the website.
- Automatic ephemeral usernames: `Anonymous1`, `Anonymous2`, `Anonymous3`, and so on.
- Usernames are not saved permanently.

## Run locally

```bash
npm start
```

Then open:

- http://localhost:3000

## Deploy target

The intended website URL is:

- https://drenplayz123.github.io/about-me

> Note: the chatroom requires the backend endpoints (`/events` and `/message`) from `server.js`.
